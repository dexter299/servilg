# Servi LG · Sitio web

Página estática (HTML, CSS y JavaScript, sin dependencias) del servicio técnico Servi LG.

## Qué editar

- `script.js`, bloque `CONFIG` al inicio: número de WhatsApp, mensaje, teléfono y horario visibles.
- `index.html`: textos, precios, técnicos y preguntas frecuentes.
- Fotos de técnicos: súbelas a `assets/` y reemplaza el bloque `tech-photo` de cada técnico (hay un comentario con el ejemplo).

## Publicar con GitHub Pages

1. En el repositorio: **Settings → Pages**.
2. En **Build and deployment**, elige **Deploy from a branch**, rama `main`, carpeta `/ (root)`.
3. Guarda. En uno o dos minutos el sitio queda en `https://<usuario>.github.io/<repositorio>/`.

## Datos del mapa

Los límites municipales vienen de datos abiertos del DANE (MGN 2021) y las comunas de Medellín del portal de datos abiertos de la Alcaldía. El relieve y el trazo del río son ilustrativos, no representan la altura real del terreno.
